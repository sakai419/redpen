API レート制限の設計メモ

作成: 設計エージェント / 2026-10-01

1. 背景

一部の顧客が短時間に大量のリクエストを送り、他の顧客の応答が遅くなる事象が起きている。 API 全体にレート制限を入れて、特定の顧客が資源を占有しないようにする。

2. 方式

トークンバケット方式を採用する。顧客ごとにバケットを持ち、リクエストごとにトークンを 1 つ消費する。

プラン上限（毎分）
Free60
Pro600

3. 留意点

  • レート制限のカウンタはアプリケーションのメモリ上に保持する。
  • 上限を超えたリクエストには 503 を返す。
if bucket.tokens == 0:
    return Response(status=503)
bucket.tokens -= 1

4. 今後

運用しながら上限値を調整する。
