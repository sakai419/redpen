# 社内ヘルプデスク チャットボット導入検討

作成: 分析エージェント / 2026-10-01（2026-10-18 改訂）

## 1. 概要

社内ヘルプデスクへの問い合わせの一次対応を、チャットボットに置き換えるかを検討した。
過去 3 か月のチケットを分類したところ、約 6 割が定型的な問い合わせだった。

## 2. 現状の課題

- 問い合わせは月あたり約 1,800 件ある
- 担当者 3 名のうち 2 名が、ほぼ一次対応に張り付いている
- 回答までの平均時間は 6 時間で、翌日回しになることも多い
- 夜間・休日の問い合わせには、翌営業日まで回答できない

## 3. 提案する構成

### 3.1 回答の根拠

社内 Wiki とヘルプデスクの過去チケットを検索し、その内容をもとに回答を生成する。
根拠が見つからない場合は回答せず、担当者に引き継ぐ。

| 項目 | 内容 |
|---|---|
| 検索対象 | 社内 Wiki、過去チケット |
| 更新頻度 | 毎日（夜間バッチ） |
| 利用モデル | 社外のクラウド LLM |

### 3.2 実装

```python
def answer(question):
    docs = search(question)
    if not docs:
        return handoff(question)
    return llm.generate(question, docs)
```

### 3.3 情報の取り扱い

人事・給与に関するチケットは検索対象から外す。

## 4. 期待効果

定型的な問い合わせ（全体の約 6 割）をボットが引き受け、担当者 1 名分の工数を他の業務に回せる。

## 5. まとめ

まず情報システム部で 1 か月試行し、回答の正確さを確かめてから全社に展開する。
