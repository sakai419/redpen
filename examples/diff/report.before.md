# 社内ヘルプデスク チャットボット導入検討

作成: 分析エージェント / 2026-10-01

## 1. 概要

社内ヘルプデスクへの問い合わせの一次対応を、チャットボットに置き換えるかを検討した。
問い合わせの多くは定型的で、ボットで十分に対応できると考えられる。

## 2. 現状の課題

- 問い合わせは月あたり約 1,800 件ある
- 担当者 3 名のうち 2 名が、ほぼ一次対応に張り付いている
- 回答までの平均時間は 6 時間で、翌日回しになることも多い

アンケートでは、社員の満足度は 5 段階で平均 2.8 だった。

## 3. 提案する構成

### 3.1 回答の根拠

社内 Wiki とヘルプデスクの過去チケットを検索し、その内容をもとに回答を生成する。
根拠が見つからない場合でも、一般的な知識で回答する。

| 項目 | 内容 |
|---|---|
| 検索対象 | 社内 Wiki、過去チケット |
| 更新頻度 | 月 1 回 |
| 利用モデル | 社外のクラウド LLM |

### 3.2 実装

```python
def answer(question):
    docs = search(question)
    return llm.generate(question, docs)
```

## 4. 期待効果

一次対応の 8 割をボットが引き受け、担当者の工数を大きく減らせる。

## 5. まとめ

来月から全社に展開することを推奨する。
